# Game Brief: 摸鱼连连看

**One-sentence pitch:** 点两块一样的图块，连得上就消掉，两分钟清空一盘，摸鱼刚刚好。

## Core loop
- 扫一眼盘面，找两块一样的图块
- 依次点这两块：连线不超过两个弯（可以绕到棋盘外圈）就画出连线并消掉
- 盘面越空路越多，越消越快，直到清盘或时间到，然后一键再来一局

## Player goal & fail state — what "working" looks like
- 目标：120 秒内消掉全部 24 对（6 列 × 8 行，12 种图块各 4 张）就算赢
- 失败：时间到还有剩余就输，结算页显示已消多少对、还剩多少

## MVP — what must exist to be the game
1. 竖屏 6×8 棋盘发牌，图块大、字大，手机宽度自适应
2. 点选两块并判断能否连通（不超过两个弯，可绕外圈），能连就画线并消除，不能连就轻轻抖一下表示无效
3. 120 秒倒计时，加上胜利和失败的结算页（用时、已消对数）
4. 死局自动洗牌：盘面没有可消的对子时，重排剩下的图块，不扣分
5. 提示按钮：每局 3 次，高亮一对可以消的
6. 再来一局：一键重开

## Out of scope — not building this
- 关卡地图、难度选择、多种棋盘形状
- 任何货币、道具商店、抽奖、每日奖励、签到
- 联网、排行榜、账号、广告
- 背景音乐（点击音效以后再加）、精细动画打磨

## Build order
1. 连通判定（两个弯以内、含外圈）加点选消除：这是最核心也最容易出错的部分
2. 发牌，以及死局检测和自动洗牌
3. 倒计时与结算
4. 提示按钮
5. 竖屏布局、大字号，在手机上实际点一点

---
**Who it's for / what they feel:** 午休摸鱼的上班族和中老年人；不用学规则，两分钟换一个“清空了”的小满足。

**Art & audio direction:** 大圆角图块、高对比暖色、水果和日常小物件图案（不用鱼，免得跟钓鱼游戏混），轻柔的点击音以后再加。

**Reference game:** 经典《连连看》（QQ 游戏 / 4399 那一版），只留“两个弯内连线消除 + 限时清盘”，不要关卡、道具、积分。
