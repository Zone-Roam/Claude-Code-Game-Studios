# 选将与解锁

> **Status**: Draft（2026-10-30，用户批准草案；还没经过 /design-review）
> **Author**: 用户 + 主会话（lean 模式）
> **Last Updated**: 2026-10-30
> **Implements Pillar**: 2 将在人为（挑谁上阵也是一个决定）、3 故事决定这一回打什么仗（主将由故事定）、5 攒得踏实（赢哪回得哪位武将）、4 一看就会（不挑也能直接开讲）

## Summary

每一回开讲前，水牌下面有一排技能槽（最多 3 个）。第一个槽是这一回的主将，由故事定，不能换；其余的槽从已解锁的武将里挑，槽位开局就按推荐阵容填好，不想挑的人直接点“开讲”。打赢哪一回，就得哪位武将。

> **Quick reference** — Layer: `Feature` · Priority: `Vertical Slice`（正式版前 10 回） · Key deps: `武将技能、回目编排与难度、进度、三星与存档、界面与交互`

## Overview

切片的第三次试玩里，用户提出想像植物大战僵尸那样，开局前把武将放进技能槽、自由组合（2026-10-29）。这和原来的支柱 3“出阵武将由故事决定”冲突，用户的取舍是：**故事定主将，其余槽自选**（2026-10-30）。这样每一回仍有它的故事主角，例如长坂坡一定有赵云，而“这一仗带谁去”成了开讲前的一个小决定，武将越攒越多，组合也越来越多。

这个系统做四件事：
- 从回目数据读出槽位数、主将和推荐阵容。
- 从进度推出已解锁的武将。
- 在水牌上让玩家换将。
- 把最终阵容交给武将技能系统，作为这一回的出阵武将。

它不改任何技能本身，技能由“武将技能”定义。

## Player Fantasy

“这一回吕布攻得快，带张飞压他的蓄力，再带赵云挡一招。”主帅在帐前点将：主将是故事给的，副将是自己挑的。挑对了，这一仗打得顺；挑错了，下次换一套再来。武将一位一位攒起来，每一位都是自己打下来的。

## Detailed Design

### Core Rules

**槽位与主将**

1. 每一回有 `slots` 个技能槽，取 1–3（回目数据字段，见“回目编排与难度”）。
2. 每一回有一位主将 `lead`（武将 id），占第 1 个槽，盖“主将”朱印，**不能换下**。
3. 每一回有推荐阵容 `recommend`（武将 id 列表，长度等于 `slots`，第一位必须是 `lead`）。它取代原来的 `generals` 字段。
4. 正式版的头几回只给 1–2 个槽，往后逐步开到 3 个。具体哪一回开几个槽，由关卡编排定，但同一回只引入一样新东西（支柱 4）：开第 2 个槽的那一回，不再同时登场新压力或新效果。
   - **例外**（用户决定 9，2026-10-30）：这一回可选武将的总数不超过 `slots`（规则 12，只显示、不展开换将）时，玩家没有东西可挑，开槽不算新东西。正式版第二回同时有敌将首登场和第 2 槽，可选只有关羽、张飞，按此例外。第五回同开第 3 槽和吕布二阶段，可选有四位，算两样新东西，用户接受。

**解锁**

5. 每一回可以写一个 `unlock`（武将 id）：**第一次**赢下这一回时，这位武将解锁。重打赢了不会再解锁别人。
6. 开局就有的武将写在数据文件的 `starters` 列表里，正式版是 `['guan_yu']`（只有关羽；用户决定，2026-10-30）。其余武将按回目解锁：第一回张飞、第三回赵云、第四回刘备、第七回诸葛亮、第八回黄忠（“回目编排与难度”规则 13）。
7. 已解锁的武将 = `starters` + 所有 `wins ≥ 1` 的回目的 `unlock`。存档里**不单独存**，每次从进度推出来（和回目解锁的做法一样，“进度、三星与存档”规则 10）。
8. 主将和推荐阵容里的武将，**这一回一律可用**，哪怕还没解锁（例如故事要求这回赵云登场，而赵云正是这回的奖励）。这一回赢了才正式解锁。

**点将**

9. 水牌下面显示一排槽位，开局按下面的顺序填好：
   1. 这一回上次的阵容（规则 13），其中仍然可用的武将；
   2. 不够的位置，用推荐阵容里还没上阵的武将依次补上；
   3. 还不够，就空着。空槽不影响开讲。
10. **换将**：点一个非主将的槽，槽下面展开可选武将。可选的是已解锁的武将，再加上规则 8 里这一回可用的武将，去掉已经在槽里的。点一位就把他放进这个槽；点槽里的“×”就把这个槽清空。
11. **不对路的武将**：这一回的 `deck` 里没有某位武将的蓄力兵时，这位武将的牌变灰，写“此回无{兵}”（例如“此回无鼓”），不能选。
12. **不显示点将的情况**：如果这一回可选的武将总数不超过 `slots`，就没什么可挑的，槽位直接按规则 9 填好，只显示、不展开换将。
13. **记住阵容**：每一回结算（`settle()`）时，把这一回实际上阵的武将 id 列表写进这一回的存档记录，字段名 `loadout`。放弃的一回不写，和星级一样（“进度、三星与存档”规则 12）。
14. 点“开讲”的那一刻，槽里的武将（按槽位顺序）作为这一回的出阵武将，交给“武将技能”。之后这一回里不能换将；“再来一回”沿用同一套阵容，回到水牌时可以再换。

### States and Transitions

| 状态 | 进入 | 离开 |
|---|---|---|
| 未解锁 | 默认 | 赢下 `unlock` 是他的那一回；或者他在 `starters` 里 |
| 已解锁 | 见上 | 不会离开（输了不会重新上锁） |
| 本回可用 | 已解锁，或是这一回的主将或推荐阵容里的人；并且 `deck` 里有他的蓄力兵 | 换到别的回目 |
| 上阵 | 在槽里时点了“开讲” | 这一回结束 |

### Interactions with Other Systems

- **武将技能**：只读本系统交出的出阵武将列表。武将牌最多 3 张，顺序就是槽位顺序。
- **回目编排与难度**：提供 `slots`、`lead`、`recommend`、`unlock`、`starters`、`deck`。加载时的检查见 Edge Cases。
- **进度、三星与存档**：提供各回 `wins`（推出已解锁的武将），保存各回的 `loadout`。
- **界面与交互**：水牌上的点将区、可选武将的展开、变灰的提示、桌沿的武将牌改成最多 3 张。
- **教学引导**：第一次出现可换的槽时，提示一次“点空槽，挑一位武将”。

## Formulas

本系统不定义数值曲线，只有一条集合计算：

```
unlocked = starters ∪ { ch.unlock | ch 能加载，且 progress[ch.id].wins ≥ 1 }
available(ch) = (unlocked ∪ {ch.lead} ∪ ch.recommend) 中，蓄力兵在 ch.deck 里的武将
pickable(ch) = available(ch) − {ch.lead}
showPicker(ch) = |available(ch)| > ch.slots
```

例子：`starters = [关羽]`。
- 赢过第一回（`unlock` = 张飞），现在打第二回：`slots` = 2，`lead` = 张飞，`recommend` = [张飞, 关羽]。`available` = {关羽, 张飞}，2 位，不多于 2 个槽，不显示点将，槽位直接是张飞、关羽。
- 再打第三回：`slots` = 2，`lead` = 赵云（这回的奖励，按规则 8 可用），`deck` 里有刀、鼓、盾。`available` = {关羽, 张飞, 赵云}，3 位，多于 2 个槽，显示点将，副将从关羽、张飞里挑一位。

## Edge Cases

- **主将的蓄力兵不在这一回的 `deck` 里**：数据错误，这一回拒绝加载（主将必须能放技能）。
- **推荐阵容里有人的蓄力兵不在 `deck` 里**：只警告；填槽时跳过他。
- **`recommend` 长度不等于 `slots`，或第一位不是 `lead`**：拒绝加载。
- **`unlock` 写了一位已在 `starters` 里的武将**：只警告，赢了也不会多出什么。
- **两回的 `unlock` 是同一位武将**：只警告，以先赢下的那一回为准。
- **存档里的 `loadout` 有不认识的武将 id、重复的 id，或者长度超过这一回的 `slots`**：只丢掉 `loadout` 这一项，按推荐阵容填，这一回的星级和胜场照用（不按“进度、三星与存档”规则 11 整条丢掉）。
- **存档里的 `loadout` 有一位现在不可用的武将**（例如改版后他的蓄力兵从 `deck` 里拿掉了）：跳过他，按规则 9 补位。
- **存储不可用**：已解锁的武将只在这一次页面会话里有效，阵容不记住，和星级的兜底一样（“进度、三星与存档”规则 17）。
- **只有 1 个槽**：只有主将，不显示点将，水牌和切片一样只多一张主将牌。
- **槽里有空位时点开讲**：照常开讲，桌沿只摆有人的武将牌。

## Dependencies

| 系统 | 方向 | 依赖什么 |
|---|---|---|
| 武将技能 | 下游 | 本系统给出的出阵武将列表 |
| 回目编排与难度 | 上游 | `slots`、`lead`、`recommend`、`unlock`、`starters`、`deck` |
| 进度、三星与存档 | 双向 | 读各回 `wins`；写各回 `loadout`（新字段，见下） |
| 界面与交互 | 下游 | 点将区和武将牌的显示 |
| 教学引导 | 下游 | 第一次换将的提示 |

**对其他文档的改动**（合并时一起改）：
- “回目编排与难度”：`generals` 改成 `recommend`，新增 `slots`、`lead`、`unlock` 字段和顶层的 `starters`；加载检查按上面的 Edge Cases 增加。
- “进度、三星与存档”：每回记录新增可选的 `loadout`（武将 id 数组）。它是可选字段，旧存档没有它也合法，所以 `v` 不用升级。校验时 `loadout` 出错只丢这一项。
- “界面与交互”：水牌加点将区；桌沿武将牌改成最多 3 张，牌可以放大。
- “武将技能”：规则 1 的“四位武将”改成“出阵武将由选将系统给出，最多 3 位”；MVP 例外取消。
- `design/gdd/game-concept.md`：支柱 3 改成“主将由故事决定，其余由你点将”（已改，2026-10-30）。
- ADR-0004（本地存档）：只加一个可选字段，不改存储方式，应该不需要新 ADR。写架构审查时再确认。

## Tuning Knobs

| 参数 | 位置 | 默认 | 安全范围 | 影响 |
|---|---|---|---|---|
| `slots` | 每回数据 | 编排决定 | 1–3 | 槽越多越好打，挑选的讲究也越多 |
| `starters` | 数据文件顶层 | 1 位（关羽） | 1–3 位 | 开局手里有几位武将 |
| `unlock` | 每回数据 | 编排决定 | 每回 0–1 位 | 武将攒得多快 |
| `SLOT_MAX` | 常量 | 3 | 3（再多桌沿放不下大牌） | 槽位上限 |

## Acceptance Criteria

（以下按正式版前 10 回的数据写：`starters = [guan_yu]`；第一回 `slots 1`、`lead guan_yu`、`unlock zhang_fei`；第二回 `slots 2`、`lead zhang_fei`、`recommend [zhang_fei, guan_yu]`；第三回 `slots 2`、`lead zhao_yun`、`recommend [zhao_yun, guan_yu]`、`unlock zhao_yun`，`deck` 有刀、鼓、盾。见“回目编排与难度”规则 13。）

- **GIVEN** 存档为空、`starters = [guan_yu]`，**WHEN** 打开第一回的水牌，**THEN** 只显示一个关羽的主将槽，没有换将按钮。
- **GIVEN** 第一回 `unlock = zhang_fei`，**WHEN** 第一次赢下第一回，**THEN** 已解锁的武将是关羽、张飞；**WHEN** 再赢一次，**THEN** 已解锁的武将不变。
- **GIVEN** 已解锁关羽、张飞，**WHEN** 第一次打开第二回，**THEN** 槽位是张飞（主将，不能换）和关羽，点第 2 个槽不展开（可选 2 位不多于 2 个槽，规则 12、规则 4 例外）。
- **GIVEN** 已解锁关羽、张飞，**WHEN** 第一次打开第三回，**THEN** 槽位是赵云（主将，不能换）和关羽；点第 2 个槽，可选的只有张飞。
- **GIVEN** 上一题的状态，玩家把关羽换成张飞，打输了第三回，**WHEN** 再打开第三回，**THEN** 槽位是赵云和张飞。
- **GIVEN** 第一次赢下第三回（`unlock = zhao_yun`），**WHEN** 推出已解锁的武将，**THEN** 是关羽、张飞、赵云。
- **GIVEN** 第三回的 `deck` 里没有鼓，**WHEN** 展开第 2 个槽，**THEN** 张飞的牌变灰，写“此回无鼓”，点了没有反应。
- **GIVEN** 已解锁关羽、张飞、赵云、刘备，第八回 `deck` 里没有旗，**WHEN** 展开第八回的槽，**THEN** 刘备的牌变灰，写“此回无旗”。
- **GIVEN** 某回 `lead` 的蓄力兵不在 `deck` 里，**WHEN** 游戏启动加载回目，**THEN** 这一回被拒绝加载，开发版控制台给出回目 id 和字段名 `lead`。
- **GIVEN** 存档里 ch03 的 `loadout` 是 `["zhao_yun", "lv_bu"]`（`lv_bu` 不是武将），**WHEN** 打开第三回，**THEN** 槽位按推荐阵容填（赵云、关羽），ch03 的星级照常显示。
- **GIVEN** 槽位是赵云和张飞，**WHEN** 点开讲，**THEN** 桌沿只有赵云、张飞两张武将牌，顺序和槽位一致，牌面比切片里的四张大。
- **GIVEN** 存储不可用，**WHEN** 同一次会话里赢下第一回再打开第三回，**THEN** 第 2 个槽能展开，张飞可选；**WHEN** 重新加载页面再打开第三回，**THEN** 张飞又回到未解锁，可选只有关羽、赵云两位，不展开换将。
