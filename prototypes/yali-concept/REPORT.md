# Concept Prototype Report: 压力连连看（兵种版 + 三种压力）

> **Date**: 2026-10-26
> **Prototype Path**: HTML
> **Concept File**: design/gdd/game-concept.md（第一版）

## Hypothesis
当压力来自盘面上看得见的东西（逼近的敌军、见底的粮草、快要出手的敌将），而不是一个数字在倒数时，玩家会觉得紧张、觉得有挑战。

## Riskiest Assumption Tested
压力会不会太凶，变成“烦人”而不是“紧张”。**用户的反馈是“挑战上来了”，没有说烦。**

## Approach
在兵种版的基础上去掉倒计时，开局卡片上可以切换三种压力。29 KB。

| 压力 | 输的条件 | 实测调参 |
|---|---|---|
| 敌军压境 | 每隔一段时间从上面压下一排；底部红区有块时再压一排，就破城 | 一开始用 6 秒间隔，机器人（每波消 3 对）赢 5/6，太紧；改成三回依次 7、6、5 秒 |
| 粮草有限 | 每消一对耗 1 份粮，点错扣 1 份，粮尽就输 | 余量 3 时，“先放效果、不点错”的机器人三回胜率 15/15、14/15、9/15，逐回上升 |
| 敌将反击 | 敌将蓄满就出手：增兵 2 对、扣你一颗心；三颗心没了就输 | 蓄力时间 10、9、8 秒；三连斩以上打断 25%，点错加 15% |

**Path chosen:** HTML　**Reason for path:** 目标平台就是浏览器。
**Shortcuts taken (intentional):** 压境的新兵随机生成（是威胁，不是奖励，不违反“无赌博感”；正式版建议改成固定波次）；网址参数 `?every=`、`?charge=`、`?slack=` 代替难度设置。

## Result
- 用户原话：“不错，现在倒是挺有意思的，挑战上来了。”
- 随后用户指出：“武将在这里面体现一个什么？好像和不同方块没有区别啊。”这引出了武将技能版。
- 自测时修了两个问题：一是面板隐藏时窗口高度接近 0，格子尺寸算成负数（六个原型都加了下限）；二是心形在楷体下显示成黑色。

| Metric | Value |
|--------|-------|
| Path used | HTML |
| Prototype duration | 约 25 分钟 |

## Recommendation: PROCEED（并入武将技能版）

压力假设成立。剩下的问题（武将没有存在感）由下一版解决，压力系统原样保留。

## Lessons Learned
- 紧迫感来自“看得见的威胁”加上“你的操作会决定输赢”，单纯倒计时两样都没有。
- 三种压力正好对应三国里三类战役：守城被追、粮道北伐、斗将单挑。编排可以直接由故事决定。
