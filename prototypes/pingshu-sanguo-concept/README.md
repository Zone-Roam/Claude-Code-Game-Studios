# 评书连连看·三国 — 概念原型

**假设**：在连连看里打出连斩、消到武将时盘内弹一句评书台词，会让人比普通连连看更想“再来一回”。判断依据：3 回里至少一次主动点“下一回”或“再来”，事后能复述至少一句台词；台词开、关各玩一局，问更想再玩哪个。

**最大风险**：台词哪怕只停 0.8 秒、期间暂停计时，也会打断连斩的爽感。

**怎么打开**：双击 `prototype.html`，任何浏览器都行，不联网。

- 看手机效果：按 F12，再按 Ctrl+Shift+M，选一款手机尺寸。
- 对比台词开和关：地址末尾加 `?line=0`，台词就关掉了。
- 调台词停留时间：加 `?linems=500` 或 `?linems=1200`，默认 800 毫秒。
- 调每回时长：加 `?time=180`。
- 参数可以组合，例如 `prototype.html?linems=1200&time=180`。
