# 兵种连连看 — 概念原型（变体 C）

**假设**：某些兵种消掉时会触发效果，一下清掉一整类块。这能带来“割草”的爽快，也让“先消哪对”有了讲究，所以不再无聊。

**怎么判断**：玩完三回后问自己三件事。
- 有没有特意去找带红框的块。
- 有没有为了“一把火多烧几个营帐”而先留着它。
- 清掉一大片那一下，爽不爽。

**规则**（效果块有红框，右下角的小图标表示它会清掉哪一种块）：
- 🔥 火攻：所有 ⛺ 营帐一起清掉。第一回开始出现。
- 🐎 铁骑：所有 🏹 弓兵一起清掉。第二回开始出现。
- 🌊 水攻：所有 🏯 城寨一起清掉。第三回才出现。

被清掉的那类块每一种都是偶数个，所以清掉之后盘面一定还能消完。每回 120 秒。

**打开方式**：双击 `prototype.html`。也可以从 `prototypes/compare.html` 进入。

**状态**：in-progress，等待试玩。
