## PIVOT chain

```text
#1 摸鱼连连看（minimal 档，未试玩）
 └─ 切 standard 档，概念换成三国 ─→ #2 评书三国：“还是连连看，有点无聊”
     └─ 调研衍生作品 ─→ #3 阵法 / #4 叠层 / #5 兵种：“都还行，但没紧迫感”
         └─ 以 #5 为底加三种压力 ─→ #6 压力版：“挑战上来了”，但“武将和方块没区别”
             └─ 武将改成盘下技能 ─→ #7 武将版：“用技能的感觉对味了” → PROCEED
```

同一个概念一共转向（PIVOT）了 2 次（#2 → 变体，变体 → 压力），没有触发模板“转向 3 次就强制考虑放弃”的规则。
