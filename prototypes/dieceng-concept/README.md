# 叠层连连看 — 概念原型（变体 B）

**假设**：盘面中间叠了两层，消掉上层才能翻开下层，武将都作为“伏兵”藏在下层。“下面是什么”的好奇心会让人想继续消下去，这是你在第一阶段选的“故事与发现”。

**怎么判断**：玩完三回后问自己两件事。一是有没有特意先去消带黑点的块，想看看下面压着什么。二是翻出伏兵那一下有没有感觉。

**规则**：
- 带黑点、往上浮起的块下面还压着一块。
- 叠了两层的格子，两块都消掉之后才算空格，连线才能从这里穿过。
- 三回的叠层区域：6×6 盘中间 2×4、6×7 盘中间 3×4、6×8 盘中间 4×4。
- 时长依次为 130、140、150 秒。
- 遇到死局时，先在原来的层里重新洗牌；实在无解，就把叠着的块摊开到空格里。

**打开方式**：双击 `prototype.html`。也可以从 `prototypes/compare.html` 进入。
