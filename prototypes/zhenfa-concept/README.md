# 阵法连连看 — 概念原型（变体 A）

**假设**：每消一对，剩下的块就按这一回的阵法整体挪动。玩家得先想“消了这对，阵会变成什么样”，比普通连连看多了一层思考，所以不再无聊。

**怎么判断**：玩完三回后问自己两件事。一是有没有为了让阵挪到想要的样子，故意先消某一对。二是比起评书三国版，更想不想再来一回。

**规则**：
- 第一回长蛇阵：每消一对，敌阵向左收拢。
- 第二回锋矢阵：向上推进。
- 第三回鹤翼阵：向左右两翼分开。
- 其余和评书三国版一样：连斩、武将台词、120 秒。

**打开方式**：双击 `prototype.html`。也可以从 `prototypes/compare.html` 进入。网址参数 `?line=0`、`?linems=`、`?time=` 和评书三国版的用法相同。
